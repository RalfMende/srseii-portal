Z21 verbinden

1. Z21-App verbinden

  1. Smartphone/Tablet mit dem WLAN der Z21 verbinden.
  2. Z21-App öffnen.
  3. In den Einstellungen die Verbindung zur Z21 auswählen.
  4. Als IP-Adresse die folgende Adresse eintragen: -
  5. Verbindung speichern bzw. herstellen.

2. WLAN-Maus verbinden

  1. WLAN-Maus einschalten.
  2. In den WLAN-Einstellungen das WLAN der Z21 auswählen.
  3. Mit dem WLAN verbinden.
  4. In den Verbindungseinstellungen der WLAN-Maus die Z21-IP-Adresse eintragen: -
  5. Verbindung bestätigen.

Wichtig

Smartphone/Tablet bzw. WLAN-Maus müssen sich im gleichen Netzwerk wie die Z21 befinden.

Hinweis zur Z21 App

Die Z21-App kann kostenlos installiert und getestet werden. In der kostenlosen Version ist die Steuerung jedoch auf eine Lokomotive beschränkt. Für die Steuerung mehrerer Lokomotiven muss die Z21-Vollversion als In-App-Kauf freigeschaltet werden.
