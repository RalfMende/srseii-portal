Z21 verbinden

1. Z21-App verbinden

  1. Smartphone/Tablet mit dem WLAN der Z21 verbinden.
  2. Z21-App öffnen.
  3. Im Menü zu Einstellungen > Z21-Einstellungen > IP-Adresse gehen.
  4. Als IP-Adresse die folgende Adresse eintragen: -
  5. Erneut mit Z21 verbinden drücken.

2. WLAN-Maus verbinden

  1. Display zeigt SSID -> Weiter mit *OK Taste.
  2. Display zeigt SEARCH -> Weiter mit *OK Taste.
  3. Mit den Pfeiltasten das gewünschte WLAN-Netz auswählen.
  4. Display zeigt PWD -> Weiter mit *OK Taste. -
  5. WLAN-Passwort eingeben. -> Weiter mit *OK Taste.

Wichtig

Smartphone/Tablet bzw. WLAN-Maus müssen sich im gleichen Netzwerk wie die Z21 befinden.

Hinweis zur Z21 App

Die Z21-App kann kostenlos installiert und getestet werden. In der kostenlosen Version ist die Steuerung jedoch auf eine Lokomotive beschränkt. Für die Steuerung mehrerer Lokomotiven muss die Z21-Vollversion als In-App-Kauf freigeschaltet werden.

Central-Station-Schnittstelle verbinden

So verbindest du dein Gerät

  1. Gerät oder App mit demselben Netzwerk wie den SRSEII verbinden.
  2. Eine kompatible Steuer-App öffnen.
  3. Als Zentrale oder Server die Central-Station-Schnittstelle auswählen.
  4. Die folgende SRSEII-IP-Adresse eintragen: -

Beispiele

RemoteCS, RailControl Pro und Mobile Station WLAN können als kompatible Clients verwendet werden, sofern ihre Schnittstellenkonfiguration dies unterstützt.
