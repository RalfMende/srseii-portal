Connect Z21

1. Connect the Z21 app

  1. Connect your smartphone or tablet to the Z21 Wifi.
  2. Open the Z21 app.
  3. In the menu, go to Settings > Z21 Settings > IP Address.
  4. Enter the following IP address: -
  5. Press Connect to Z21 again.

2. Connect the Wifi mouse

  1. Display shows SSID -> Continue with *OK button.
  2. Display shows SEARCH -> Continue with *OK button.
  3. Use the arrow keys to select the desired Wifi network.
  4. Display shows PWD -> Continue with *OK button. -
  5. Enter the Wifi password -> Continue with *OK button.

Important

The smartphone, tablet, or Wifi mouse must be connected to the same network as the Z21.

Note on the Z21 app

The Z21 app can be installed and tested free of charge. In the free version, control is limited to one locomotive. To control multiple locomotives, the full Z21 version must be unlocked through an in-app purchase.

Connect the Central Station interface

Connect your device

  1. Connect the device or app to the same network as the SRSEII.
  2. Open a compatible control app.
  3. Select the Central Station interface as the central station or server.
